Overview

This project presents a financial dashboard created using Power BI.
It analyzes company performance based on sales, profit, and units sold.

Tools Used

- Power BI
- HTML
- CSS

Dataset

The dataset includes:

- Country
- Product
- Segment
- Sales
- Profit
- Units Sold
- Date (Month & Year)

Features

- KPI cards for Sales, Profit, Units Sold
- Sales by Country (Map)
- Sales by Product (Bar Chart)
- Sales by Segment (Pie Chart)
- Monthly and Yearly Trends

Output

The dashboard provides insights into:

- Top-performing products
- High sales regions
- Sales trends over time
- Effect of discounts on profit

Note

Due to embedding restrictions in Power BI Service, the dashboard is displayed as an image.
